# Lost & Found Map App

An Android mobile application developed in Java using Android Studio, SQLite, and Google Maps API. The app allows users to create lost or found item adverts, upload images, save locations, and display items on an interactive map with radius-based filtering.

## Features

- Create Lost / Found adverts
- Upload image for each advert
- SQLite local database storage
- View all adverts in RecyclerView
- Category filtering
- Remove adverts
- Google Maps integration
- Get current device location
- Display saved adverts as map markers
- Radius-based search filtering

## Technologies Used

- Java
- Android Studio
- SQLite
- Google Maps SDK
- RecyclerView
- XML Layouts
- Android Location Services


## Purpose

The purpose of this app is to help reconnect lost items with their owners through a mobile platform that supports geo-location and map-based item searching.
